# 阵营差异化设计 · 三大文明

> 目标：把"三方同质"升级为三大文明的打法差异。每个文明回答三个问题：
> **什么时候强（时间窗）· 靠什么赢（胜利路径）· 怕什么（被克制面）**。
>
> 架构红线（不变）：所有差异**数据驱动**（CivDef 查表），确定性内核不加随机分支；
> 阵营修正集中在 createWorld 定死、运行时查表计算。

---

## 0. 时间窗三角（设计骨架）

```
游牧 ●━━━━━━━━━○          （0-4 分钟强势期：掠夺滚雪球）
        骑士 ●━━━━━━━━━━○   （3-8 分钟：单兵质量碾压期）
                中原 ●━━━━▶  （5 分钟后：塔阵+人海+经济纵深，越拖越强）
```

- **游牧怕拖**：人口上限低、高阶兵弱，必须前期打出优势
- **骑士怕消耗**：兵贵（金效率低），被游击/人海磨就亏
- **中原怕快攻**：塔阵和农田成型前最脆弱

## 2. 文明数值修正表（单位层面）

> 修正原则：差异挂在**伤害/血/速度/造价**四个旋钮上，克制网三文明共用。

### 中原王朝（人海 + 阵地）
- T1 步兵/长枪兵 **造价 -15%**（人海引擎）
- 全单位速度 **-8%**（机动差）
- 重装/近卫军 血 +15%（阵地 turtle 的硬前排）
- 训练时间 **-10%**（爆兵快）

### 草原游牧（机动 + 掠夺）
- 全单位 **速度 +18%**
- 骑士/游骑兵 **造价 -10%**（马匹便宜）
- 箭塔（若有）造价 +60%；近卫军 dps -15%（后期高阶兵乏力）
- 人口 70

### 圣辉骑士团（单兵质量）
- 全单位 **血 +22%、伤害 +15%**
- 全单位 **造价 +25%、训练时间 +20%**（精锐的代价）
- 速度标准

> 校准基准：同人口会战，骑士团 ≈ 赢中原前中期、输中原大后期；游牧 4 分钟前白嫖两家、10 分钟后打不过任何一家。

## 3. 中原专属：农田 + 塔体系

**农田（farm）**——不占矿点的第二经济：
- 60 金 / 血 200 / 建造 6s / 收入 **3/s**（低于金矿 4/s）
- 建在**建造区内任意空地**（不绑矿点），上限 **8 座**
- 意义：经济纵深——矿被拆了农田还在；8 农田 = 24/s 的安全底线收入
- 造型：田垄（棕黄条纹格子）+ 稻穗点缀；图标 = 田字格

**箭塔任意建造（带约束）**：中原箭塔绕过建造区限制，但必须满足
**「己方存活单位 250px 内」**——塔阵跟着部队走（攻城塔阵），有真实反制手段：
歼灭护卫部队则孤立塔暴露可拆。无约束的自由建塔会演变成无解的一步一塔（review 修正）。

**塔升级（新指令 `upgradeTower`）**：选中塔 → 升级按钮（150 金 → 300 金，共 2 级）
- 每级：血 +40%（520→728→1019）、伤害 +40%、射程 +15
- 升级耗时 8s / 12s，**升级期间停止攻击、血量保持**（可被打断节奏，不损失进度）
- 视觉：塔身加高 + 旗升级（2 级挂阵营大旗）
- 意义：后期防御 investing——一座 3 级塔 ≈ 半支军队

## 4. 游牧专属：掠夺 + 游骑兵

**掠夺（plunder）**：
- 击杀敌方单位：获得其**造价 ×30%** 黄金
- 摧毁敌方建筑：获得其**造价 ×25%** 黄金（溅射击杀同样触发）
- 掠夺金计入战报总收入（earned）
- 意义：把"进攻"变成经济引擎——拆一座军械库回 100 金，杀 10 个步兵回 150 金；前期主动出击是理性选择而非赌博
- 表现：掠夺金音效（金币叮声已有）
- 反制链自查：游骑兵射程 100 < 中原弓手 125 < 箭塔 175——风筝不是无解，
  对面站桩远程和塔都能反点；游牧自己没有 125+ 射程单位（内建克制）

**游骑兵（horsearcher，替换游牧的弓手位）**：
- 120 金 / 2 人口 / 血 70 / 速度 **100** / 射程 100 / dps 12×0.8s=15
- 定位：骑射风筝——比弓手快 11%、比骑士便宜，打了就跑
- 剪影：马身（骑士的马简化）+ 短弓；徽记：羽翎
- 游牧**弓手卡替换为游骑兵卡**（HUD 按文明渲染）

**前期引擎**：军营造价 -15%（120）、训练时间 -10%——3 分钟内可拉出第一波骑兵潮。

## 5. 圣辉骑士团：全员精锐 + 战术素养

- 全单位血 +22%、伤害 +15%（同人口会战全面占优）
- **战术素养**：所有克制加成 **+0.3**（弓手→重装 1.9、长枪→骑士 2.1…）——
  克制网对骑士团更锋利，"练兵+战术"的双重人设，避免三家里最无记忆点
- 造价 +25%、训练 +20%：等价黄金对比不占优——**输给数量，赢给质量**
- 文明说明文案：「你的每一支部队都贵于对手——永不主动换家，永远寻求会战」

## 6. AI 阵营化——不再是一个换皮的固定状态机

> 原则：AI 的**决策骨架统一**（状态机：扩张→攒兵→波次→回防→溃退），但每个文明
> 通过一份 **AIProfile 行为参数表** 表现出完全不同的打法风格。对手文明也是开放信息，
> AI 会**针对性调整**（knowYourEnemy）。AI 与玩家同规则受益文明修正。

### 6.1 AIProfile 行为参数表（CIVS 内，跑批校准）

| 参数 | 中原 | 游牧 | 骑士 | 说明 |
|---|---|---|---|---|
| `earlyAggro` | 1.3 | **0.55** | 1.0 | 首波时间倍率：游牧 3 分钟内第一波 |
| `wavePopMul` | **1.2** | 0.6 | 1.15 | 人海攒大军 vs 小股快袭 |
| `waveCdMul` | 1.2 | **0.55** | 1.0 | 游牧波次间隔最短 |
| `waveMaxMul` | 1.25 | **0.3** | 1.0 | 游牧波次 ≈28s，打完就跑 |
| `raidMode` | — | **✓** | — | 只拆矿不打塔/城堡（掠夺优先），到时强制撤退 |
| `towerPush` | **✓** | — | — | 攻城推进时随军起塔（见 6.3） |
| `towerTarget` | **4** | 0（塔贵不建） | 2 | 塔数量目标 |
| `farmTarget` | **8** | — | — | 农田数量目标（矿≥5 后持续补） |
| `defendRadius` | 300 | 240 | 300 | 回防半径 |
| `armyMix` | 步兵/弓手/长枪 | **骑士/游骑兵/重装** | 重装/长枪/近卫 | 出兵配比覆盖 |

### 6.2 三文明的 AI 打法画像

**中原 AI——龟缩发育，塔阵碾过去**
1. 前期（0-5min）：双矿→军营→**农田持续补到 8**；在基地与矿区间起 2 座塔并升级；
   防守反击（wavePop 1.2 倍=攒大军才出门，waveCd 1.2=节奏慢）
2. 后期（人口 >60 或 8 分钟后）：进入**塔阵推进**——每次波次出击时，随军在推进方向
   起塔（金够、部队 250 内、塔数未达 4+2/波）；塔阵落地后下一波从塔后发起
3. 兵力真空期（科技攒钱）照旧——中原本就该龟

**游牧 AI——掠夺快袭，打了就跑**
1. 开局：军营**前置**（建造区朝质心一侧），首波 2.5-3 分钟即出（earlyAggro 0.55）
2. `raidMode`：波次目标**只选敌方矿**（拆矿=掠夺赚钱），waveMax 0.3 倍（约 28s）——
   到点**强制撤退**（即便占上风），撤回后再来下一波；绝不围攻城堡/箭塔
3. 掠夺金加速滚雪球：`applyDamage` 掠夺钩子自动生效
4. 弱势处理：人口 70 上限、近卫 dps -15%——10 分钟后 AI 转入防守（towerTarget 0
   的游牧守不住，靠剩余骑兵骚扰牵制）

**骑士 AI——质量会战，稳扎稳打**
1. 标准 build order + 正常科技节奏；wavePop 1.15 倍（质量部队要凑够再打）
2. 不追特殊花样：靠修正后的单兵质量在正面会战打出交换比
3. knowYourEnemy：对上游牧时 waveMax -20%（防被游击放风筝），对上中原时
   earlyAggro 0.8（别让龟塔拖进大后期）

### 6.3 knowYourEnemy——按对手文明的针对性调整

对手文明是开放信息（菜单已选）。AI 在 aiSide 开头读对手文明，叠加微调：

| 我方 | 对手 | 调整 |
|---|---|---|
| 任意 | 游牧 | 回防半径 +80（掠夺更警惕）；有塔文明塔优先升 1 级（防骚扰）；波次 waveMax -20%（防被拖） |
| 任意 | 中原 | earlyAggro ×0.8（抢在塔阵成型前）；波次目标**优先拆农田**（断经济纵深） |
| 任意 | 骑士 | 无特殊（质量对质量，避免过拟合） |
| 三人局 | 多对手 | 取「最近交战过/最近敌方」的文明作为参考对手 |

### 6.4 实现落点（ai.ts 重构为「统一骨架 + 文明参数」）

```
aiSide(w, side):
  profile = CIVS[w.civs[side]].ai          // 行为参数
  enemyCiv = 最近对手文明                    // knowYourEnemy
  adjusted = applyKnowYourEnemy(profile, enemyCiv)
  ...统一骨架（现状逻辑），所有魔法数字改读 adjusted.*
  中原专属分支：towerPush（attacking 时随军起塔）、farmTarget 补农田
  游牧专属分支：raidMode（pickGoal 只选矿 + waveMax 到点强制撤退）
  出兵替换：游牧 pickUnit 权重中 archer → horsearcher（armyMix 已表达）
```

**工程要点**：DIFFICULTY（难度）与 AIProfile（文明风格）正交相乘——难度管数值强度，
文明管打法风格，二者不耦合；跑批可独立扫描。

## 8. 对局分配规则

- **1v1**：玩家选文明，AI 从其余两文明**随机**选一（透明、无针对）
- **三人局**：玩家选自己的，两个 AI 分配剩余两文明（天然剪刀石头布）
- AI 与玩家同规则：受益文明修正 + 按 AIProfile 打法风格行动（行为适配在本轮 V1 内）

### 校准注记（review 轮 2 补充）

1. **游牧首波数学**：wavePopMul 0.6 × 普通 40 = 24 人口门槛；游牧军营 120 金/-10% 训练时间
   下约 3 分钟可达标（earlyAggro 0.55 × 45s waveCd ≈ 25s 首波冷却）。探针校准点：
   游牧 AI 首波应在 3±0.5 分钟出现——早于 2.5 分钟说明过强，晚于 3.5 说明军营前置没生效。
2. **中原塔计数分离**：家防塔（towerTarget 4，建造区内）与推进塔（每波 +2，随军）**分开计数**，
   推进塔不挤占家防预算；全局上限 8（防 AI 无限造塔卡死经济）。
3. **raidMode 波次叠加**：游牧 waveMax = 95×0.3 ≈ 28s（对骑士 knowYourEnemy ×0.8 ≈ 23s）——
   校准探针验证 28s 内 2 游骑能否拆掉 320 血金矿（15dps×2 ≈ 21s，可拆完）；
   撤退条件 =「目标矿摧毁 或 waveMax 到点」先到为准。
4. **农田与建造区容量**：8 农田 ×4 格 = 32 格，占 20×20 建造区的 8%——空间无虞；
   建造区轮廓可视化（已实现）会让玩家看清农田摆放空间。


### 校准注记（review 轮 3 补充：工程影响与 AI 细节）

1. **createWorld 签名扩展的全局影响**：`createWorld(difficulty, seed, mapIndex, civs?)`——
   civs 缺省时三方默认 `['central','nomad','knight']`（2 人局 `['central','nomad']`）。
   **全部 83 个测试、balance.ts、探针无需改动即通过**（走默认值）；新增「文明依赖」专项测试
   （修正数值进对局、掠夺金、塔规则、农田）。
2. **游牧 AI 不建工坊**：AIProfile 加 `workshopTarget: boolean`——游牧 false（900 金省下堆骑兵，
   近卫 dps -15% 不值得）；AI 出兵配比里 catapult/champion 权重清零。
3. **AIProfile 的落点**：并入 `CIVS[civ].ai`，与 DIFFICULTY 正交相乘（难度×文明风格独立扫描）。
4. **玩家文明选择的持久化**：localStorage 记住上次选择（zw_civ）。

## 10. 平衡校准方法

- 跑批支持指定对阵：`ZW_CIV=nomad:central npm run balance -- 12 600`
- 关键矩阵（1v1）：游牧vs中原、骑士vs中原、游牧vs骑士、同文明镜像（对称性检查）
- 目标：**无绝对最优文明**——每个对阵胜率落在 35-65% 区间；镜像对局 ≈ 50%
- 三人局：三方各分配一文明（天然的剪刀石头布）

## 11. 风险与明确不做

- **风险**：文明修正 × 克制网 × 科技档 × AI 行为四维叠加，平衡空间指数膨胀——
  控制手段：AIProfile 参数全部可跑批扫描（ZW_CIV + 难度正交）；接受 V1「基本可玩」，
  精校按你的实机反馈迭代。AI 行为差异本身也是平衡变量（游牧 AI 变凶会改变全矩阵），
  校准顺序固定：先数值后行为，每轮只动一层
- 不做：文明专属科技树（数值差异已足够 V1）、文明专属地图、语音差异化
- **明确接受的简化**：V1 的 knowYourEnemy 是查表微调而非真正的战略 AI；
  AI 不会诈败、不会佯攻、不会针对玩家操作习惯——那需要行为树/效用系统，超出本轮
