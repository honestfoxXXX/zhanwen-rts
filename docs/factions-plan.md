# 阵营差异化设计 · 三大文明

> 目标：把"三方同质"升级为三大文明的打法差异。每个文明回答三个问题：
> **什么时候强（时间窗）· 靠什么赢（胜利路径）· 怕什么（被克制面）**。
>
> 架构红线（不变）：所有差异**数据驱动**（CivDef 查表），确定性内核不加随机分支；
> 阵营修正集中在 createWorld 定死、运行时查表计算。

---

## 0. 时间窗三角（设计骨架）

```
游牧 ●━━━━━━━━━○          （0-4 分钟强势期：掠夺滚雪球）
        骑士 ●━━━━━━━━━━○   （3-8 分钟：单兵质量碾压期）
                中原 ●━━━━▶  （5 分钟后：塔阵+人海+经济纵深，越拖越强）
```

- **游牧怕拖**：人口上限低、高阶兵弱，必须前期打出优势
- **骑士怕消耗**：兵贵（金效率低），被游击/人海磨就亏
- **中原怕快攻**：塔阵和农田成型前最脆弱

## 2. 文明数值修正表（单位层面）

> 修正原则：差异挂在**伤害/血/速度/造价**四个旋钮上，克制网三文明共用。

### 中原王朝（人海 + 阵地）
- T1 步兵/长枪兵 **造价 -15%**（人海引擎）
- 全单位速度 **-8%**（机动差）
- 重装/近卫军 血 +15%（阵地 turtle 的硬前排）
- 训练时间 **-10%**（爆兵快）

### 草原游牧（机动 + 掠夺）
- 全单位 **速度 +18%**
- 骑士/游骑兵 **造价 -10%**（马匹便宜）
- 箭塔（若有）造价 +60%；近卫军 dps -15%（后期高阶兵乏力）
- 人口 70

### 圣辉骑士团（单兵质量）
- 全单位 **血 +22%、伤害 +15%**
- 全单位 **造价 +25%、训练时间 +20%**（精锐的代价）
- 速度标准

> 校准基准：同人口会战，骑士团 ≈ 赢中原前中期、输中原大后期；游牧 4 分钟前白嫖两家、10 分钟后打不过任何一家。

## 3. 中原专属：农田 + 塔体系

**农田（farm）**——不占矿点的第二经济：
- 60 金 / 血 200 / 建造 6s / 收入 **3/s**（低于金矿 4/s）
- 建在**建造区内任意空地**（不绑矿点），上限 **8 座**
- 意义：经济纵深——矿被拆了农田还在；8 农田 = 24/s 的安全底线收入
- 造型：田垄（棕黄条纹格子）+ 稻穗点缀；图标 = 田字格

**箭塔任意建造**：中原箭塔绕过建造区限制（地图任意可建格），防御纵深外扩——塔阵推进成为合法战术。

**塔升级（新指令 `upgradeTower`）**：点塔 → 升级按钮（150 金 → 300 金，共 2 级）
- 每级：血 +40%（520→728→1019）、伤害 +40%、射程 +15
- 视觉：塔身加高 + 旗升级（2 级挂阵营大旗）
- 意义：后期防御 investing——一座 3 级塔 ≈ 半支军队

---

## 4. 游牧专属：掠夺 + 游骑兵

**掠夺（plunder）**：
- 击杀敌方单位：获得其**造价 ×30%** 黄金
- 摧毁敌方建筑：获得其**造价 ×25%** 黄金
- 意义：把"进攻"变成经济引擎——拆一座军械库回 100 金，杀 10 个步兵回 150 金；前期主动出击是理性选择而非赌博
- 表现：掠夺金飘字/音效（金币叮声已有）

**游骑兵（horsearcher，替换游牧的弓手位）**：
- 120 金 / 2 人口 / 血 70 / 速度 **100** / 射程 100 / dps 12×0.8s=15
- 定位：骑射风筝——比弓手快 11%、比骑士便宜，打了就跑
- 剪影：马身（骑士的马简化）+ 短弓；徽记：羽翎
- 游牧**弓手卡替换为游骑兵卡**（HUD 按文明渲染）

**前期引擎**：军营造价 -15%（120）、训练时间 -10%——3 分钟内可拉出第一波骑兵潮。

---

## 5. 圣辉骑士团：全员精锐

无新建筑/兵种，**数值本身就是特性**：
- 同人口会战 dps/血 全面占优（比如 12 骑士团重装 ≈ 打 16 别文明重装）
- 但等价黄金对比打平甚至略亏——**输给数量，赢给质量**
- 搭配提示（给玩家的文明说明文案）：「你的每一支部队都贵于对手——永不主动换家，永远寻求会战」

## 6. 实现架构

| 层 | 改动 |
|---|---|
| types.ts | `CivId = 'central' \| 'nomad' \| 'knight'`；World +`civs: CivId[]`；UnitType +`horsearcher`；BuildingType +`farm`；Command +`upgradeTower`；Tower +`level` |
| config.ts | `CIVS: Record<CivId, CivDef>`（修正表 + 规则参数 + 名称/文案）；farm/horsearcher 数值 |
| sim.ts | createWorld 写入 civs；train/canPlace/popCap/applyDamage(掠夺)/fireAt 查文明表；upgradeTower 指令 |
| shapes/renderer | 游骑兵建模（马身+短弓）、农田造型、塔升级视觉、图标 |
| hud/index | 菜单文明三选一；卡槽按文明渲染（游牧弓手→游骑兵；中原多农田卡）；塔升级按钮 |
| ai.ts | AI 用分配文明走数值修正（自动受益）；行为适配 V2 |
| balance.ts | `ZW_CIV=p0:p1` 环境变量指定对阵文明，输出交叉矩阵 |

**确定性要点**：`w.civs` 在 createWorld 定死并纳入 hashWorld/序列化；所有修正查表无随机。

## 8. 平衡校准方法

- 跑批支持指定对阵：`ZW_CIV=nomad:central npm run balance -- 12 600`
- 关键矩阵（1v1）：游牧vs中原、骑士vs中原、游牧vs骑士、同文明镜像（对称性检查）
- 目标：**无绝对最优文明**——每个对阵胜率落在 35-65% 区间；镜像对局 ≈ 50%
- 三人局：三方各分配一文明（天然的剪刀石头布）

## 9. 风险与明确不做

- **风险**：差异修正 × 克制网 × 科技档三维度叠加，平衡空间指数膨胀——用交叉矩阵跑批控制，接受 V1"基本可玩"，精校放 V2
- 不做：文明专属科技树（数值差异已足够 V1）、文明专属地图、语音差异化
- AI 行为适配（游牧速攻/中原龟塔）放 V2——V1 AI 靠数值修正自动获得部分特性
