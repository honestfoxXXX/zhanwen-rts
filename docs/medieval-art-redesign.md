# 美术风格重构方案：架空中世纪欧洲

> 目标：把当前"霓虹水晶"科幻风整体替换为**架空中世纪欧洲**风 ——
> 草地荒野、泥土路、城堡要塞、金矿脉、骑士长弓手、羊皮纸 UI、纹章配色。
>
> 硬约束（执行时全程不得违反）：
> 1. **只动表现层**。`src/core/sim.ts`、`src/core/ai.ts`、`src/core/config.ts` 的数值与逻辑、
>    `scripts/balance.ts` 一律不碰。改完后 83 个测试必须全过，1v1/3 人胜率基线不得漂移
>    （本方案不涉及任何模拟行为，理论上零漂移）。
> 2. **阵营 = 颜色，兵种 = 剪影** 的双通道识别原则不变，只换颜色值与剪影造型。
> 3. 所有阵营色仍由 `src/render/shapes.ts` 的 `SIDE_*` 单一出处，其它模块一律 import，不得另立色号。

## 2. 单位设计（`shapes.ts`）

保留现有渲染技法（椭圆投影、阵营底环、剪影内左上高光 + 右下暗面、徽记不随朝向旋转），
只改**剪影与徽记**。剪影原则：步兵=圆盾、弓手=尖顶、骑士=盾形，三个轮廓在 9px 半径下也必须一眼可辨。

### 2.1 步兵 → 持盾剑士（silhouette: circle，沿用）
- 徽记 `'dot'` 改为 `'boss'`：**盾心**——中心一颗亮圆点 + 上半圈深色盾缘弧线（`arc(0,0,vr*0.55, PI, 0)`）。
- 朝向指针（现有的深色短线）保留，读作"剑尖"。

### 2.2 弓手 → 长弓手（silhouette: arrow，沿用）
- 徽记 `'ring'` 改为 `'quiver'`：**弦月**——一道朝上的弧线（`arc(0, vr*0.1, vr*0.5, PI*1.15, PI*1.85)`）
  + 中心竖直箭杆短线。徽记不旋转，弦月朝上即可，读作箭囊。

### 2.3 重装 → 骑士（silhouette: hex → 改为 heater shield 盾形）
`shapePath` 新增 `'heater'`，替换 hex：

```
g.moveTo(-r, -r * 0.5);
g.quadraticCurveTo(-r, -r, 0, -r);        // 顶部弧
g.quadraticCurveTo(r, -r, r, -r * 0.5);
g.lineTo(r * 0.55, r * 0.35);              // 两肋内收
g.lineTo(0, r * 1.1);                      // 底部尖
g.lineTo(-r * 0.55, r * 0.35);
g.closePath();
```

- 徽记 `'plates'`（双横杠）改为 `'cross'`：**十字**——竖条 + 横条各一根（`vr*0.16` 宽），读作骑士盾上的十字。
- `UNIT_SHAPES.heavy` 的 `shape` 改 `'heater'`，`bob: 0` 不变（沉重感）。

### 2.4 HUD 卡槽图标
`drawIcon` 复用 `drawUnitBody` 自动生效，无需另改。

## 4. 地面（`renderer.ts` 的 `buildBackground`，预渲染，细节免费）

1. **基底**：垂直渐变（§1.2），去除棋盘格后的既有结构不变。
2. **色斑**：草甸/褐土两族椭圆（沿用现有随机循环，换色即可），暗斑保留。
3. **泥土路（重点新增）**：从每个出生点画一条到地图质心的路：
   ```ts
   for (const sp of map.spawns) {
     const mx = (sp.pos.x + cx) / 2 + (sp.pos.y - cy) * 0.08;  // 控制点略偏，形成自然弯
     const my = (sp.pos.y + cy) / 2 - (sp.pos.x - cx) * 0.08;
     g.strokeStyle = 'rgba(60,42,24,0.35)'; g.lineWidth = 30;
     g.beginPath(); g.moveTo(sp.pos.x, sp.pos.y); g.quadraticCurveTo(mx, my, cx, cy); g.stroke();
     g.strokeStyle = 'rgba(138,106,66,0.55)'; g.lineWidth = 22;
     g.beginPath(); g.moveTo(sp.pos.x, sp.pos.y); g.quadraticCurveTo(mx, my, cx, cy); g.stroke();
   }
   ```
   `cx,cy` = 出生点均值。1v1 是两条纵向主路到前线会合，3 人是三条路到质心。画在岩石之前。
4. **岩石**：多面体结构保留，主体改 `#6d6a63`，亮面 `rgba(205,203,195,0.22)`，裂纹 `rgba(48,44,36,0.55)`，
   顶部加 1-2 块苔藓斑 `rgba(110,150,80,0.25)`。
5. **前线**：虚线与箭头保留，颜色见 §1.2；文案 `—— 前 线 ——` → `—— 国 境 线 ——`。
   三方质心标注 `必 争 之 地` → `王 冠 之 地`。
6. 草茎、碎石点、基地平台光晕、四边压暗：保留（草茎换色见 §1.2）。
