# 三视角审阅：游戏性 / 画面 / 音效 / 操作 / UI

> 审阅人视角：游戏测评师（系统与深度）、游戏小白（前 10 分钟）、路人（前 30 秒）。
> 依据：实机截图（菜单/开局/会战三帧）、全量代码走读、自动化操作回放。
> 本文档同时记录审阅中发现并已当场修复的问题，与留待后续的问题清单。

---

## 〇、审阅中当场揪出并修复的 Bug

1. **菜单"活战场"只画了地形**——上一轮把演示模式的 early-return 插在了渲染序列的水晶层之后、
   建筑/单位/弹道/特效之前，背景永远是"没有军队的空地图"。已重构为贯穿式 chrome 门控，
   菜单背后现在是真实的 AI 混战（部队行军、交战、掉血全部可见）。
2. **屏内告警四边全红**——会战帧实测整屏被 0.55 透明度的红边淹没，战斗本身反而看不清。
   已降为轻量全屏脉动 + 交战点红晕。
3. **菜单压暗过重**（0.42→0.28），rock 主题灰底上直接黑成剪影。

## 一、路人视角（前 30 秒：我为什么点进来，为什么留下）

| 维度 | 评价 | 依据 |
|---|---|---|
| 画面 | ★★☆☆☆ → ★★★☆☆ | 修复前菜单是一块深蓝纯色加几行字——没有任何"世界"。修复后背后是真实进行的攻防：行军纵队、交战火光、掉血条，"这是一场战争"一眼成立。但整体仍偏暗（rock 主题 + 压暗层），第一帧的色彩冲击力不足 |
| 音效 | ★☆☆☆☆ | 菜单**完全无声**。浏览器自动播放策略下音频要等首次交互，而首交互通常就是点"开战"——菜单静默可以被理解，但连一点氛围铺垫都没有，路人感觉像打开了一个 demo 工程页 |
| UI | ★★★☆☆ | 菜单文案干净（难度/模式/文明三段选择 + 一句副标题），文明描述诚实且和数值一致。但"战纹"两个字没有视觉符号呼应，favicon 是个孤零零的金菱形——品牌感为零 |
| 操作 | —（菜单无操作） | 点击即进，无注册无加载，这点是加分项 |
| 游戏性 | ★★★☆☆ | 从活战场能直接读到"这是即时战略、有三方、在抢金矿"——信息传达成立 |

**结论**：修完菜单后，路人留步的概率实质提升；但"最后 1 秒"（点开战之前的听觉/品牌印象）仍是空白。

## 二、小白视角（前 10 分钟：我能不能玩明白）

| 维度 | 评价 | 依据 |
|---|---|---|
| 游戏性 | ★★★★☆ | 目标链（占矿→军营→12 兵→军械库→决战）随局势打勾，照着做就能赢下简单局；首局提示一次讲完核心操作；AI 不会开局就碾压 |
| 操作 | ★★★★☆ | 右键下令、卡片造东西、WASD 平移——鼠标流 3 分钟上手；热键角标就在卡片上。扣一星：Shift+右键（强制移动）和 Ctrl+左键（攻击移动）只存在于提示文字里，实战中没有场景逼你学会它们 |
| UI | ★★★★☆ | 人口/黄金/收入一屏可读；选中面板把"攻/程/速"直接给出来；被攻打时顶栏+消息流+小地图三处提醒。扣一星：目标链与消息流同在左侧，640px 高的屏幕上会叠 |
| 画面 | ★★★☆☆ | 建筑领地色晕让"这是谁的地盘"可读；单位比旧版大 40%+。但**当你需要找敌人时，画面帮不了你**——被打只剩文字告警和边角红光，镜头不会带你去 |
| 音效 | ★★☆☆☆ | 命令确认、命中、死亡有声音分层。但低音铺底是最近才加的，且**音乐永远是一个循环**——打了十分钟，耳朵里还是开头那 8 秒的变体 |

**小白最大的一条断点**：第一次被 AI 拆矿时，多数人不知道该做什么——告警说"城堡遇袭"，但新手还没学会"点小地图/按 Tab"跳过去。缺一个被动镜头牵引或高亮教学（哪怕只在简单难度）。

## 三、测评师视角（系统、深度与长期动力）

| 维度 | 评价 | 关键论据 |
|---|---|---|
| 游戏性 | ★★★☆☆ | 骨架完整且真实：科技门禁、文明配比、克制链、王冠终局全部在跑（本轮已探针证实）。但**深度瓶颈在"决策密度"而非系统数量**：经济 = 铺矿（单变量），军事 = A 上去（自动接战+自动分层），防守 = 塔守家。真正的决策点只有"什么时候开科技"和"什么时候决战"。农田调价后抢矿必要性恢复了，但扩张路线本身没有分支（没有 商业/中立野怪/第二资源） |
| 画面 | ★★★☆☆ | 本轮修了色彩层级（主题提饱和、领地色晕、告警降噪）。剩余短板按权重：①单位死亡仍是"碎片散开"，没有倒地/残骸持续存在（战场打完像没打过）；②建筑无受击抖动；③弹道先结算后飞（已知权衡）；④UI 字体是无衬线系统字，缺中世纪气质 |
| 音效 | ★★☆☆☆ | 代码层已分层（低音铺底随战况开合、双鼓连击、胜负 stinger 重做为鼓滚+全奏号角）。但合成音色的"材质感"天花板明显：金属声还是 FM 味、没有弓弦/皮革/人声。测评师会写"功能完备，听感廉价" |
| 操作 | ★★★★☆ | WASD 回归后桌面手感达标；编队、集结、升级、图鉴齐全。缺：框选只认部队不认建筑（混合编队做不了）、无"选中同类全部"的扩展键（双击仅限视野内） |
| UI | ★★★☆☆ | 信息架构完整。缺：小地图上没有战争迷雾记忆（故意移除了）但也没有"最后见过敌人"的残影——信息价值打折；结算只有数据没有过程回放 |

**测评师总评**：这是一个"规则可靠性刚达标、内容深度待扩"的 Demo。当前最好的部分是确定性内核 + 三文明 + 王冠终局的组合潜力；最差的部分是**感官层仍不足以让人愿意打完第二局**——本轮修复（菜单活战场、色彩层级、音乐纵深、胜负仪式）正是冲着这个去的，但音色材质化和死亡表现这两块，程序化合成的边际收益已经很低。

## 四、修复优先级建议（按"留住玩家"排序）

1. **简单难度加镜头牵引教学**（被打时自动平移半程 + 高亮来敌 2 秒，可设置关闭）——小白的最大断点
2. **残骸持续存在**（30s 渐隐的尸体剪影/残垣）——战场记忆感，成本低收益高
3. **音乐二层**：至少做"和平/战斗"两套已实现的编曲切换（骨架已有，缺编曲差异）
4. **品牌一分钟**：菜单加一行世界观副标 + 把 favicon/标题字做成"战纹"纹章；音频策略允许后加开场鼓点
5. **真机移动端测试**（一直没做，竖屏触控是产品定位的核心假设，不能永远靠推断）

## 五、已在本轮落地的对应项

- 菜单活战场渲染修复 + 压暗校准（路人/画面）
- 屏内告警降噪：全屏红 → 脉动 + 交战点红晕（画面/信息）
- 低音铺底随战斗烈度开合、双鼓连击、胜负 stinger 重做（音效）
- 主题色提饱和提亮、昼夜色温减淡、建筑领地色晕（画面/色彩层级）
- 死亡碎片加重带抛物线（画面/反馈）
- 胜利仪式：镜头推近胜方城堡 1.5s 后再弹结算（游戏性/情绪）
