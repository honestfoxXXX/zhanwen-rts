# 视觉 · 操作 · 交互 整体优化方案（待确认）

> 原则：不动模拟内核数值与 AI 行为（平衡基线不漂移）；不引入位图素材（保持全程序化绘制）；
> 新增指令走指令流（lockstep 兼容）。每个里程碑收尾跑 83 测试 + 双模式跑批 + 浏览器截图验收。

---

## 一、现状诊断

### 视觉（依据 3P 实战截图 + 渲染代码）

| # | 问题 | 证据 |
|---|---|---|
| V-1 | **尺度感崩坏**：默认视野宽 820 世界像素，单位屏幕直径 ~11css px、城堡 ~26px——兵海像蚂蚁打架，兵种剪影不可辨，战斗没有规模感 | 默认档截图 |
| V-2 | **战斗无打击感**：命中无受击反馈、近战无挥砍动画、死亡无尸体/碎片，读不出"谁在打谁、谁在掉血" | drawUnit/drawBuilding 只有呼吸+血条 |

| V-4 | **王冠之地无锚点**：3P 核心胜利机制在地图上没有任何视觉实体，地图质心就是普通绿地 | 底图无质心地物 |
| V-5 | **HUD 风格分裂**：卡片图标是蓝灰色 emoji 字符（⛺🗼⚗），与金色羊皮纸主题脱节 | index.html 字符图标 |
| V-6 | 画面空旷：大图 ×0.75 预渲染后大片纯绿；暗角偏重（0.30-0.32） | 3P 截图 |

## 二、方案设计

### 包 A：战场可读性与视觉表现

**A1 尺度重构（V-1，最高优先）**
- 默认缩放档从「视口宽 820」改为「视口宽 ~560 世界像素」（scale≈0.88），概览/极限档不变；
- 单位绘制放大 `rMul` 全线 +15%；建筑主体绘制放大 1.2×（碰撞 half 不动，只改画）；
- 城堡旗/火把/雉堞对比度增强。
- 验收：开局一屏最多容纳 ~14 个单位身位；步兵/弓手/骑士剪影一眼可辨。

**A2 打击感系统（V-2）**
- 受击闪白：命中瞬间实体叠加 80ms 白层（`source-atop` 白矩形，缓存精灵上可做）；
- 近战 lunge：攻击时向目标位移 3px 弹回（渲染偏移，不进 sim）；
- 死亡表现：尸体 0.8s 淡出 + 3-5 片阵营色碎片 + 短暂土痕；
- 伤害数字：上飘小字，可关（设置项），默认开；
- 爆炸统一两档：投石车大弹=土石飞溅+震屏，箭矢=粉尘扑。
- 验收：交战 10s 录屏，肉眼可读交战关系与血量走势。

**A3 文明建筑皮肤（V-3）**
- 中原：箭塔四角翘檐+红柱、城堡红墙金瓦、农田已有；
- 游牧：军营改圆顶毡帐、金矿加木栅栏、旗帜改狼徽；
- 骑士团：城堡挂盾徽旗、箭塔顶十字旗、石色更冷。
- 实现点：`paintBuildingStatic` / `drawBuildingIcon` 按 `civOf` 分支细节层（主体骨架共享）。
- 验收：三文明开局截图并排，一眼分辨。

**A4 王冠之地地标与终局仪式感（V-4）**
- 质心预渲染石制祭坛地标；`CROWN_WINDOW-30s` 起点亮金色光柱+脉动光环；
- 占领中：地面画 350 半径占领方色环 + 小地图质心闪点；
- 结算胜因标注（"王冠之地占领成功" / "扫平全部城堡" / "超时平局"）。
- 验收：3P 局 330s/360s/占领中三张截图状态分明。

**A5 HUD 皮肤统一（V-5）**
- 全部卡片图标改用 canvas 精绘（复用 `drawBuildingIcon`/`drawUnitBody`，替换 emoji 字符）；
- 卡片状态：可买=金边微光呼吸，不可买=降饱和+差价标注；
- 面板加亚麻噪点纹理与金色描边（CSS 渐变叠加，无图）。
- 验收：HUD 与战场同框截图风格统一。

**A6 地面密度与氛围（V-6，轻）**
- 草簇/野花密度 ×1.5；加 8-10 处战场遗迹装饰（断矛、残盾、石堆）；
- 暗角 0.30→0.22；河流加芦苇丛。
- 验收：开局与中期截图无大片纯色空地。

### 包 B：操作升级

**B1 热键全覆盖（C-1）**
- 建造卡 `Q W E R T Y`（金矿/军营/箭塔/军械库/工坊/农田），出兵卡 `1 2 3 4`；
- `F` 全选军队、`G` 集结、`U` 升级箭塔、`I` 升级金矿、`Tab` 循环跳告警点；
- 卡片右上角热键角标；菜单提示同步。
- 验收：纯键盘完成「建矿→建营→出兵→集结→升级」全流程演示。

**B2 编队系统（C-2）**
- `Ctrl+1..5` 存编队、`1..5` 召回、连按两次 `1..5` 镜头跳转；
- 屏幕左下编队槽 UI（小圆标+兵种数量），触屏长按槽=分配、点按=召回。
- 验收：前线编队拉扯 + 后方补兵的两线操作演示。

**B3 攻击-移动与强制移动（C-3）**
- 现状语义保留：右键空地=移动（自动接战）；
- 新增 `Shift+右键 / 双指点击` = **强制移动**（新指令 `moveForced`，Order 内不接战直走到点）；
- 新增 `A+左键` = 显式攻击移动（与移动同语义，照顾习惯）。
- 指令流新增一条可序列化指令，历史指令不变。
- 验收：弓手组"打了就跑"微操演示。

**B4 镜头手感（C-4）**
- 缩放平滑：目标 scale + 每帧 lerp（12%）；重置/跳转镜头同样缓动；
- **取消告警抢镜头**：改为边缘方向指示器（加粗+脉冲）+ 小地图闪点，`Tab` 手动循环跳转；
- 桌面端边缘滚动（可选开关，默认开）。
- 验收：缩放录屏无跳变；告警期间不打断玩家框选。

**B5 建造 QoL（C-5）**
- 幽灵旁实时显示不可建原因（领地外/压矿/太近/挡路），文字跟随幽灵；
- `Shift+确认` 连续放置（钱不够或 Esc 才退出）；
- 中原专属：箭塔拖线连造（沿拖动路径每 2 格预览塔位，一次确认批量下单，指令流仍逐条 build）。
- 验收：Shift 连造 3 塔；中原拖线造 4 塔演示。

### 包 C：交互与引导

**C1 新手目标链（U-1，核心）**
- 右上角可折叠目标链：占金矿 → 建军营 → 训 10 兵 → 建军械库 → 终局（1v1=摧毁城堡 / 3P=守住王冠之地）；
- 每步完成打勾+音效+下一步高亮；进度持久化（localStorage），可关；
- 3P 特有步骤：「360s 后驻军质心 45s 即胜」在开局就写明。
- 验收：无头实测——零文档玩家（脚本按目标链操作）能在 8 分钟内打赢简单 1v1。

**C2 选中信息面板（U-2）**
- 底部卡片上方浮层：按兵种分组的头像+数量、聚合血量、攻击/射程/速度一行、克制提示；
- 点建筑：等级/训练队列进度/集结点状态；点敌方单位：基础情报（侦察感）。
- 数据全部查 `UNIT_DEFS`/`BUILDING_DEFS`，禁止手写第二份。
- 验收：混编选中截图信息完整；数值与 config 一致（测试钉住）。

**C3 科技与文明透明化（U-2）**
- 菜单选文明展示 3 条特性（已有，扩充为"打法建议"）；
- 局内「图鉴」按钮：弹层显示 8 兵种解锁条件/克制表/三文明差异；
- 开局 toast：「对手：草原游牧 · 掠夺机动，小心你的金矿」。
- 验收：图鉴弹层截图；克制表由 config 生成。

**C4 告警分级与定位（U-3）**
- toast 改左侧消息流（最多 3 条：告警红/提示金/普通灰，自动消退）；
- 告警附带小地图闪点（1.5s 三次脉冲）+ 边缘方向指示加粗；
- 分级：城堡遇袭 > 矿线遇袭 > 部队接敌。
- 验收：被袭 1 秒内可从小地图指出方位。

**C5 结算与设置（U-4/U-5）**
- 结算加：胜因、王冠进度、本局关键事件 3 条（首次推矿/最大团战/王冠争夺）；
- 设置面板：主音量/音乐/音效三轨、屏幕震动开关、边缘滚动开关、目标链开关；存 localStorage 实时生效；
- 暂停菜单整合（继续/设置/重开/回主菜单）。
- 验收：设置项实时生效并持久化。

## 三、执行顺序（每步可独立验收/回滚）

1. **M1 操作骨架**：B1 热键 + B3 移动语义 + B4 镜头（体验断层最先修）
2. **M2 信息与引导**：C1 目标链 + C2 选中面板 + C4 告警
3. **M3 视觉尺度**：A1 缩放与体积 + A2 打击感
4. **M4 文明与仪式感**：A3 皮肤 + A4 王冠地标 + A5 HUD 皮肤 + A6 地面
5. **M5 余项**：B2 编队 + B5 建造 QoL + C3 图鉴 + C5 结算/设置
6. **M6（可选）**：D 项按你拍板插入

验收纪律：每里程碑 83 测试零漂移 + `npm run balance` 双模式基线比对 + 桌面/触屏两套交互过一遍 + 关键界面截图留档。

## 四、明确不做

- 不引入位图/音频素材文件（全程序化底线不动）；
- 不调平衡数值与 AI 行为（M1-M5 为纯表现+输入层；若验收发现必然牵连，单独提出）；
- 不改确定性内核结构（新增指令走指令流，hashWorld 兼容字段不含渲染态）；
- 联机仍不在范围。
