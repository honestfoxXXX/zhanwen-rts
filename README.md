# 战纹 · 竖屏 RTS

竖屏（9:16）上下对峙的即时战略游戏：你在下方发展基地，敌方 AI 在上方，推平对方主基地获胜。
手机浏览器与电脑浏览器均可直接游玩（后续可用 Capacitor 打包上架）。

## 运行

```bash
npm install
npm run dev        # 开发服务器（局域网可访问，手机同网直接开玩）
npm run test       # Vitest 单元测试（模拟核心）
npm run build      # 产物构建（dist/，任意静态托管可部署）
```

## 玩法

- **胜负**：摧毁敌方主基地（上方红色）即胜，己方主基地被毁即败。
- **经济**：主基地被动产钱；地图上有 10 个水晶矿点（含 4 个中路争夺点），花 100 水晶在矿点上建 **矿场**（+5/s）。
  中路矿点双方都可争夺。收入即兵力。右侧小地图雷达可总览战局、点按跳转视野。
- **建筑**：矿场（经济）/ 兵营（解锁造兵，可多建并行排队）/ 箭塔（防守）。
  建筑只能在己方半场放置（矿场除外），有施工时间，施工中可被摧毁。
- **兵种**：步兵（50，便宜近战）/ 弓手（80，远程脆皮）/ 重装（200，肉盾高伤）。
  人口上限 40。
- **操作**：所有移动指令都是**攻击型移动**，部队沿途自动交战。
  - 触屏：单指拖动平移镜头；点选部队 → 点目标下令；双击部队选中屏幕内同类；
    底部「全选」一键选中全军；「集结」设定新兵集结点；建筑先点按钮再点地图定位，✓ 确认。
  - 鼠标：左键点选 / 框选（空地拖动），右键下令；WASD/方向键平移；滚轮平移；Esc 取消。

## AI 对手

三档难度（简单 / 普通 / 困难）：收入倍率、扩张上限、进攻波次与撤退决策均不同。
AI 会铺矿扩张 → 攒兵 → 达到阈值后波次进攻；家被偷会全军回防；战损过大且开启撤退时会收缩。

## 架构（为联机留后路）

```
src/
  core/    确定性模拟核心（纯 TS，无 DOM）：固定步长 60Hz，种子随机，
           所有操作都是 Command 对象（未来联机只同步指令流即可 lockstep）
    sim.ts         世界状态 / 指令 / 移动战斗 / 经济生产 / 胜负
    pathfinding.ts A* 寻路（8 向 + 视线平滑）+ 最近可用格
    ai.ts          AI 状态机
    config.ts      全部数值（单位 / 建筑 / 地图 / 难度）集中在此，便于平衡
  render/  Canvas 2D 渲染层 + 相机 + 特效（纯视觉，不影响模拟）
  input/   触屏 / 鼠标统一映射为 Command
  ui/      DOM HUD（顶栏 / 卡槽 / 提示 / 结算）
```

渲染目前使用几何图形 + 配色（我方青色 / 敌方玫红 / 水晶紫），后续可替换为正式素材；
`core/` 与渲染完全解耦，可整体迁移到 PixiJS。
